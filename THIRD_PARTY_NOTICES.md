# Third-party software

WojteX includes third-party PHP libraries when distributed as an installer ZIP.
The project's MIT licence does not replace their licences.

`composer.lock` records the dependency names, versions, upstream sources and
licence declarations. The installer retains the upstream licence files under
`vendor/`. Laravel and its dependencies are not claimed as original WojteX code.

The repository includes test code but not bundled dependencies. Development
dependencies installed with Composer have their own licences as well.
